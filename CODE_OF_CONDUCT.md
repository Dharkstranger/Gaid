# Code of conduct

GAID follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, be specific, assume good intent, and leave anyone's
identity, background or language out of an argument about code.

Report unacceptable behaviour privately to the maintainers through this
repository's **Security** tab → **Report a vulnerability**, marked
"conduct". Reports are read by the maintainers only.
